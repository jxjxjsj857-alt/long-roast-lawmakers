The Long Roast: Lawmakers and the File They Cannot Convert — a program that writes one satirical sentence (173 characters) roasting the lawmakers who write the law that will govern AI for the next decade, yet cannot convert their own bill into a PDF, so they email it to an intern named Kevin.

## Run it

```sh
python3 main.py
```

It writes the sentence to `/output/entry.txt`.
